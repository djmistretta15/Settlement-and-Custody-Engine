Multi-Chain Settlement

Atomic settlements across Ethereum, zkSync, Optimism, Arbitrum, and Base with verified finality.

Threshold Custody

FROST (Schnorr) and GG18 (ECDSA) threshold signatures with HSM integration.

MEV Protection

Private transaction submission via Flashbots. Prevent front-running and sandwich attacks.

L2 Cost Optimization

Intelligent routing to minimize gas costs. Up to 99% savings vs L1 settlements.

Cross-Chain Finality

ZK proof verification and optimistic rollup monitoring with reorganization detection.

Real-Time Subscriptions

WebSocket subscriptions for settlement updates, signature sessions, and gas prices.

Example Query

Query Settlements with Finality Status 
query GetSettlements {
  settlements(
    filter: { status: [FINALIZED], chain: [ETHEREUM] }
    pagination: { first: 10 }
  ) {
    edges {
      node {
        id
        sender
        receiver
        amount
        status
        finality {
          status
          finalityType
          timeToFinality
          proof
        }
        createdAt
      }
    }
    totalCount
    aggregates {
      totalVolumeUsd
      successRate
    }
  }
}
Subscribe to Settlement Updates 
subscription WatchSettlement($id: UUID!) {
  settlementUpdated(id: $id) {
    id
    status
    txHash
    finality {
      status
      confirmations
      requiredConfirmations
    }
    updatedAt
  }
}

mutation CreateWallet($input: CreateWalletInput!) {

    id
    name
    address
    scheme
    threshold
    totalParticipants
    publicKey
    policy {
      maxTransactionAmount
      dailyLimit
      requireKYC

  }
}
